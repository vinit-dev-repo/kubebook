# 25 - Helm Dependencies - Sub-charts, Aliases, Conditions, Tags, Global and Imported Values, and Starter Charts

The charts of this chapter in the state a reader can use them. `frontend` (0.1.1) and `backend` (0.2.1, with its `exports`) are the two child charts that the chapter's `make_child` function writes and later changes. `kubebook-ch25-shop` is the parent as the install and upgrade blocks use it, with the backend behind the condition `backend.enabled`. `common` is the library chart and `app` the application that includes it. The chapter rewrites the parent's `Chart.yaml` and `values.yaml` many times to show one feature at a time; those versions are in the tutorial, not here. Run `helm dependency update kubebook-ch25-shop` and `helm dependency update app` before you render them.

`starters/kubebook-starter` is the starter chart that the chapter writes into Helm's own starters folder (`$(helm env HELM_DATA_HOME)/starters`). Copy it there to use it with `helm create NAME --starter kubebook-starter`.
